# 📌 Project Overview

This project focuses on the **detection of fake Aadhaar cards using Machine Learning and Deep Learning techniques**. The system is designed to classify Aadhaar cards as **real or fake** based on extracted image features and trained prediction models.

The project was developed using **Python in Spyder IDE** and combines traditional Machine Learning algorithms with Deep Learning models to improve prediction accuracy and reliability.

The implementation includes:

* Image preprocessing
* Feature extraction
* CNN model training
* SVM and Random Forest classification
* GUI-based authentication system
* Accuracy and loss visualization

This project demonstrates the practical use of AI in **document verification and fraud detection systems**.
